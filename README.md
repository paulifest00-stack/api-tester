# ⚡ API Key Tester & Balance Checker

Aplicativo web responsivo (Desktop & Mobile) ultra-rápido para testar chaves de API, validar status de funcionamento e extrair créditos/saldo restantes.

Projetado com a filosofia de **Design Engineering de Emil Kowalski** e diretrizes de interface da **Apple (iOS HIG)**.

## 🚀 Como Usar
Basta abrir `index.html` em qualquer navegador ou rodar `npm start` para acessar via rede local.
